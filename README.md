# 🏥 Hospital Database System – SQL

A fully structured relational database system designed for managing core hospital operations.  
This project includes SQL scripts for creating tables, inserting sample data, defining relationships, and executing analytical queries.  
Developed as part of my first-year coursework for the **BSc (Hons) Artificial Intelligence and Data Science** degree at the **Informatics Institute of Technology (IIT)**.

---

## ✨ Features

- 🗂️ **Complete Database Schema**
  - Tables for patients, doctors, appointments, treatments, departments, and more.

- 🔗 **Relational Integrity**
  - Properly designed **foreign key relationships** connecting all entities.

- 📊 **Analytical & Operational Queries**
  - Queries for statistics, reporting, and hospital workflow management.

- 🧪 **Sample Data**
  - Pre-inserted records to test database functionality.

---

## 🛠️ Technologies Used

- **MySQL** (or SQLite / PostgreSQL depending on environment)
- **SQL DDL** (CREATE, ALTER, DROP)
- **SQL DML** (INSERT, UPDATE, DELETE, SELECT)
- **Relational Database Design**

---

## 📂 How to Use

1. Install a database system  
   - Recommended: **MySQL**, **XAMPP**, or **MySQL Workbench**

2. Open your SQL editor of choice.

3. Import or execute the SQL files in the correct order:
   - `create_tables.sql`
   - `insert_data.sql`
   - `queries.sql`

4. Run the provided queries to:
   - Retrieve patient and doctor details  
   - View appointments and treatment records  
   - Generate analytical insights
